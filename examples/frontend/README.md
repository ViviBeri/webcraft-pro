# Frontend Engineering Examples

These examples are reusable planning aids and illustrative patterns, not a runnable application or a claim of browser verification.

- [Architecture decision record](architecture-decision-record.md) — document consequential choices and reversibility.
- [Component contract matrix](component-contract-matrix.md) — define variants, states, semantics and observable behavior.
- [Responsive verification matrix](responsive-verification-matrix.md) — record viewport, zoom, input and content stress checks.
- [Accessible form pattern](accessible-form-pattern.md) — a minimal semantic HTML example with associated instructions and errors.

Use the smallest artifact that makes a decision or verification reproducible. Adapt examples to the product's stack, browser support policy and user journeys.
