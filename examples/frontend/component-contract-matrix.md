## Contract review

- [ ] API is minimal and typed.
- [ ] Impossible combinations are excluded or rejected.
- [ ] Native semantics and browser behavior are preserved.
- [ ] Async work handles cancellation or stale results.
- [ ] Long and localized content is supported.
- [ ] Tests assert observable behavior and keyboard paths.
- [ ] At least one real consuming context is verified.
