# Design Intelligence Examples

These examples are reusable working documents for the Stage 2 skills. They contain no third-party assets or copied skill text.

## Files

- [Design brief template](design-brief-template.md) — capture product truth, user task, art direction, design calibration, tokens and constraints before implementation.
- [Design review scorecard](design-review-scorecard.md) — score the rendered result using evidence, record severity and prioritize improvements.

## Recommended workflow

1. Use the brief template to record confirmed facts, assumptions and design decisions.
2. Use [design direction](../../skills/design-direction/SKILL.md) to define the visual system.
3. Use [design system architecture](../../skills/design-system-architecture/SKILL.md) when reusable tokens and components need to be formalized.
4. Use [anti-slop UI](../../skills/anti-slop-ui/SKILL.md) when an existing interface needs an ordered redesign pass.
5. Use the scorecard with [visual design review](../../skills/visual-design-review/SKILL.md) after implementation.

A scorecard based on source inspection alone is not a rendered visual review. Mark unavailable evidence as not assessed.
