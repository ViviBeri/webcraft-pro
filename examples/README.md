# Examples

This directory contains practical engineering examples, verification fixtures, and reusable templates for WebCraft Pro skills. It does not currently contain complete showcase applications.

## Existing content

- `accessibility/` — audit templates, semantic review checklists, screen-reader test matrices, and deterministic HTML fixtures used by keyboard/focus tests.
- `benchmark/` — an illustrative comparison of a flawed React form and a skill-guided accessible version. These files are not captured model outputs and do not constitute an executable or reproducible benchmark.
- `design/` — design brief, asset-directory, and design-review templates.
- `frontend/` — accessible form examples and architecture, component-contract, and responsive-verification templates.
- `motion/` — motion engineering examples and guidance.
- `performance/` — performance audit, budget, investigation, and test templates.
- `security/` — OWASP mapping, security verification, and security review templates.
- `test-page.html` — a deterministic page fixture for browser-check workflows.

## Planned reference applications

Complete, independently verifiable reference applications (such as a SaaS dashboard, e-commerce experience, or agency website) are future work. Do not describe these planned applications as existing examples until their source, setup instructions, and verification evidence are present.

## Documentation requirements

Each future complete reference application should document:

- Technology choices and architectural boundaries.
- Relevant WebCraft Pro skills and standards.
- Setup and execution instructions.
- Accessibility, security, and performance considerations.
- Reproducible verification steps and actual results.
