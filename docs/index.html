Raw AI output

FRAGILE

A clickable container needs custom keyboard and focus behavior.

<div
  class="button"
  onClick={handleSubmit}
>
  Submit
</div>
  • No native button semantics
  • No built-in keyboard activation
  • Focus behavior must be added
✓

WebCraft Pro guidance

SEMANTIC

Use a native button and let the platform provide expected behavior.

<button
  type="submit"
  aria-label="Submit form"
>
  Submit
</button>
  • Native button semantics
  • Keyboard activation built in
  • Accessible name is explicit

For visible button text, that text normally supplies the accessible name; use aria-label when a control has no visible text or needs a more specific name.
