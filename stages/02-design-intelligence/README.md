# Stage 2 — Design Intelligence

## Purpose

Translate product context, user needs and brand constraints into a distinctive visual direction, coherent design system, intentional page journey and evidence-based interface critique.

- [Design direction](../../skills/design-direction/SKILL.md) — brief, art direction, visual calibration, tokens and the human confirmation gate.

- [Anti-slop UI](../../skills/anti-slop-ui/SKILL.md) — ordered redesign passes that preserve product truth.
- [Premium landing pages](../../skills/premium-landing-pages/SKILL.md) — visitor journey, information architecture and working conversion paths.

## Design quality and verification

Apply product-specific visual direction, deliberate page composition, meaningful structural variety and evidence-based review. Require clear differentiation between pages, coherent information hierarchy and interactions that support the user journey. Use the shared design-quality standard and current platform guidance; do not treat any single visual style or page structure as universal.

## Acceptance boundary

Stage 2 establishes design intent and review practice. It does not claim browser validation of a consuming website, WCAG conformance, conversion improvement or performance gains. Those require project-specific implementation and testing.
