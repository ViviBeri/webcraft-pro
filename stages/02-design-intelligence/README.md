## Acceptance gate

- [ ] Each skill has an explicit trigger, workflow, decision criteria and completion checklist.
- [ ] Guidance is original and does not merely route users to external repositories.
- [ ] Visual critique is grounded in rendered evidence and product context.
- [ ] Responsive, accessibility and content-integrity constraints are integrated.
- [ ] Reference behavior and licenses are checked before any adaptation.
