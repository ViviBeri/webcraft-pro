## Acceptance gate

- [ ] Guidance distinguishes CSS motion from GSAP orchestration.
- [ ] Timelines and ScrollTriggers have explicit lifecycle cleanup.
- [ ] Responsive and reduced-motion alternatives are implemented.
- [ ] Scroll behavior does not hijack native navigation or scrolling.
- [ ] Performance is profiled rather than inferred from animation syntax.
- [ ] Examples are tested against the current GSAP API.
