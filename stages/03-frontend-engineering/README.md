# Stage 3 — Frontend Engineering

## Purpose

Translate requirements into maintainable, framework-aware frontend architecture, reusable components, responsive layouts, modern CSS and safe form behavior.

## Acceptance gate

- [ ] Guidance begins with repository inspection and preserves the existing stack.
- [ ] Architecture decisions include trade-offs and incremental migration.
- [ ] Component guidance covers API design, states, semantics and tests.
- [ ] Responsive guidance covers reflow, zoom, touch and content priority.
- [ ] Forms validate on the server and provide accessible errors.
- [ ] Examples are runnable or clearly labeled as illustrative.
