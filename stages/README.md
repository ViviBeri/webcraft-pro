# WebCraft Pro — Eight-Stage Architecture

This is the shared navigation index for the complete toolkit. Each stage folder records its purpose, canonical assets, dependencies and acceptance criteria.

The stage folders organize the work; they do **not** duplicate Agent Skills. Canonical, portable skills remain under `skills/<skill-name>/SKILL.md`. Shared engineering baselines remain under `standards/`. Agent adapters point to the same source of truth.

## Completion policy

A stage is not complete because a directory or link exists. Its acceptance criteria must be met, its references checked, its examples validated where applicable, and its claims supported by repository evidence.

The root [README](../README.md) is the public overview. The [skills index](../skills/README.md) is the canonical skill catalog. The [standards index](../standards/README.md) is the canonical engineering baseline catalog.
